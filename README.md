A collection of shareable Claude skills for teams and individuals who want to get more out of AI: faster results, better prompts, fewer interruptions.

These skills work with [Cowork](https://www.anthropic.com/claude) and Claude.ai. Install one and Claude will automatically apply it to your conversations!

---

## What's a skill?

A `.skill` file is a small instruction set you install into Claude. Once installed, Claude reads it and adjusts its behaviour accordingly — no prompting required on your end.

Think of it as a standing briefing you give Claude once, so you never have to repeat yourself.

---

## Skills

| Skill | What it does |
|---|---|
| [prompt-efficiency-coach](./prompt-efficiency-coach.skill) | Passively monitors your chat for token waste and surfaces a one-line nudge when it spots something. Also does on-demand workflow reviews. |
| [morning-brief](./morning-brief.skill) | Daily briefing pulled from your connected tools: calendar, email, Jira, and more. Onboards itself on first run. |
| [voice-setup](./voice-setup.skill) | Interviews you about your writing style, saves it to memory, and outputs a portable voice prompt you can use anywhere. |
| [profile-builder](./profile-builder.skill) | Interviews you and writes a clean, paste-ready Claude profile (Settings → Profile). Also audits and cleans up existing profiles. | 


> To install: click the skill link → **Raw** → Save As → upload to Claude via Settings → Skills.

More coming — contributions welcome.

---

## How to install

1. Download the `.skill` file from the skill's folder
2. In Claude (Cowork or claude.ai), open **Settings → Skills**
3. Click **Install skill** and upload the file
4. That's it — Claude will apply it automatically from your next conversation

## Contributing

Got a skill to share? Open a PR. Keep it:
- **Generic** — no org-specific tooling or jargon
- **Focused** — one skill, one job
- **Passive-friendly** — don't make Claude noisy or interruptive
